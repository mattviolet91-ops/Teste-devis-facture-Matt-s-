# Recette — vérifications avant l'utilisation réelle

Cochez chaque point sur le téléphone (application ouverte depuis l'écran d'accueil).

## Réglages
- [ ] Entreprise : nom, adresse, SIRET, téléphone, email, site, **médiateur de la consommation**, IBAN
- [ ] Apparence : logo et icône corrects
- [ ] Assurance : dates 2026, **attestation PDF ajoutée**
- [ ] Documents PDF : **déchetterie renseignée**, CGV relues, page de couverture
- [ ] Emails : Gmail connecté, **email de test reçu**, modèles relus, messages SMS / WhatsApp relus
- [ ] Mon compte : **notifications activées**, notification de test reçue
- [ ] Sauvegardes : « Télécharger ma sauvegarde complète » fonctionne

## Parcours complet
- [ ] Créer un client (avec recherche d'adresse) et son chantier
- [ ] Créer un devis depuis la bibliothèque, avec une photo prise depuis le devis
- [ ] Vérifier le PDF (couverture, assurance, CGV, photos)
- [ ] Envoyer le devis par email à **votre propre adresse** : bouton « Voir et accepter le devis »
- [ ] Ouvrir le lien sur le téléphone, signer : notification « Devis accepté » reçue
- [ ] Facturer un acompte de 40 %, l'envoyer, encaisser un paiement partiel puis le solde
- [ ] Facture de solde : l'acompte est bien déduit
- [ ] « Modifier » une facture envoyée : avoir + facture corrigée
- [ ] Supprimer une facture : elle ne compte plus dans le chiffre d'affaires ni dans « Encaissé »
- [ ] Envoyer un devis par WhatsApp et par SMS (message prérempli)
- [ ] Accueil : périodes, montant à encaisser, « À faire »
- [ ] Recherche globale : un client, un n° de devis, un n° de téléphone
